# Fuel Sale - Test Cases

## Scope

The test cases cover the core Fuel Sale functionality of a demo Fuel Station POS

- fuel pump selection;
- fuel type selection;
- fuel quantity validation;
- price calculation;
- cash and card payments;
- fuel dispensing;
- transaction creation;
- receipt generation;
- payment failure scenarious.

## Test Data

- Minimum fuel quantity: 1 L
- Maximum fuel quantity: 100 L
- Maximum decimal precision: 2 decimal places
- Example fuel type: A-95
- Example fuel price: 55.50 UAH/L
- Payment methods: Cash, Bank Card
